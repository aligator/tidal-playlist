# C-1 · XSS in `impressum-modal.ts` — server data unescaped in innerHTML

**File:** `web/src/components/impressum-modal.ts`

## Description

Server-returned impressum data was interpolated directly into `innerHTML` without
escaping. Any XSS payload in `IMPRESSUM_NAME`, `IMPRESSUM_ADDRESS`, or `IMPRESSUM_EMAIL`
env vars would execute in the user's browser context.

## Resolution

Fixed — server data is now escaped before rendering.
