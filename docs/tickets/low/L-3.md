# L-3 · Cookie `secure` flag may mismatch between set and delete

**File:** `server/routes/auth.ts` L57–60

## Description

`oauthCookieOptions` derives `secure` from request protocol (see H-2). If protocol
differs between set and delete requests, browser ignores the delete — stale cookie persists.

## Fix

Resolve after H-2 is fixed. Ensure consistent `secure` flag derivation for both set and delete.
