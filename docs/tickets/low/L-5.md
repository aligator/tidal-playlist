# L-5 · No request access log

**File:** `server/` (no middleware exists)

## Description

No access-logging middleware. Auth failures, 4xx/5xx patterns, and abuse are invisible
in production logs.

## Fix

Add structured access-log middleware: method, path, status, duration, anonymised IP.
