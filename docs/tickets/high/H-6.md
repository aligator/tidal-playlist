# H-6 · `style-src` CSP blocks Material Web inline style injection — widespread UI breakage

**File:** `server/main.ts` L34

## Description

```
"style-src 'self' https://fonts.googleapis.com"
```

Material Web (`@material/web`) uses `element.style.setProperty()` extensively for CSS
custom-property tokens and interactive states. Every such call is blocked. Confirmed:

- **Settings page:** `md-list-item` rows render only last 2–3 chars — unreadable.
- **Slider:** thumb renders at position 0 visually despite JS value being 20.
- **Country / Tracks selects:** visual label not applied; selects appear empty.
- **Icons:** Material Symbols font-variation-settings blocked; ligatures render incorrectly.
- **9+ CSP errors on every page load.**

## Fix Options (pick one)

1. Add `'unsafe-inline'` to `style-src` only — acceptable if XSS surface fully controlled.
2. Per-request nonce injected into CSP header and each MWC component (complex, requires SSR).
3. Pre-compute and whitelist all required style hashes (fragile — breaks on MWC version bumps).

**Recommended:** option 1, combined with strict `script-src` (already in place) and existing `frame-ancestors 'none'`.
