# A-5 · No lint task in `deno.json` or CI

**File:** `deno.json`

## Description

No `deno lint` task, no ESLint config for frontend, no CI enforcement.

## Fix

Add `"lint": "deno lint server/ && deno lint web/src/"` to `deno.json`; add CI step.
