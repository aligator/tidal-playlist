# A-14 · `ui-search-sheet.ts` search input is raw `<input>` — should be `md-filled-text-field`

**File:** `web/src/components/ui-search-sheet.ts` L118–127

## Description

```html
<input class="search-input" type="search" … />
```

30+ lines of CSS manually reproduce Material-style focus, caret colour, placeholder
colour, and font inheritance. `md-filled-text-field` handles all of this and stays
on-theme when design tokens change.

## Fix

```typescript
import '@material/web/textfield/filled-text-field.js';
// template:
html`<md-filled-text-field
  type="search"
  .placeholder="${this.placeholder}"
  autocomplete="off"
  @input="${this._onInput}"
></md-filled-text-field>`
// Remove .search-row, .search-input CSS.
```
