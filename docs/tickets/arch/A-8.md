# A-8 · `Math.random()` used for all randomisation

**File:** `web/src/modules/tidal/filters.ts`

## Description

Not cryptographically secure. Acceptable for playlist shuffling — but undocumented,
so future contributors may assume CSPRNG properties.

## Fix

Add a comment stating `Math.random()` is intentional for non-security playlist shuffling.
