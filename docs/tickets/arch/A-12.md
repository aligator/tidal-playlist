# A-12 · `settings-view.ts` double-fires handlers — export/import/logout fire twice

**File:** `web/src/modules/settings/settings-view.ts` L122–156

## Description

Each settings row binds the same handler on both the `md-list-item` and its slotted
inner button. Click on inner button fires event, which bubbles up and triggers
`md-list-item` handler too — two calls per click:

- **Export:** creates two `Blob` URLs, triggers two download dialogs.
- **Import:** calls `fileInput.click()` twice — two file-picker dialogs race.
- **Logout:** called twice (idempotent but wasteful).

## Fix

Remove `@click` from the inner button/icon-button — let `md-list-item` be the sole
click target. The trailing button is decorative in this pattern.
